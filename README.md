
# Electra

Electra یک پروژه‌ی مبتنی بر Django برای مدیریت و اجرای سیستم‌های رای‌گیری و برگزاری پنل‌های انتخاباتی است.  
این پروژه با هدف یادگیری، آزمایش و توسعه‌ی قابلیت‌های مختلف در زمینه‌ی بک‌اند و سامانه‌های انتخاباتی طراحی شده است.

> این پروژه به‌صورت منبع‌باز برای یادگیری و توسعه‌ی بیشتر در دسترس است، اما استفاده از نام پروژه بدون اجازه‌ی مالکین مجاز نمی‌باشد.

---

## ✨ ویژگی‌های اصلی

- مدیریت پنل‌های انتخاباتی
- ثبت و مدیریت کاندیدها
- سیستم رای‌گیری
- مدیریت کاربران و مدیران
- ساختار قابل توسعه برای افزونه‌ها و قابلیت‌های جدید

---

## 🛠 تکنولوژی‌ها

- **Backend:** Django
- **Frontend:** SSR
- **Database:** MariaDB

---

## 📁 ساختار پروژه

- `core_apps/` : ماژول‌های اصلی پروژه
- `template/` : فایل‌های HTML قالب
- `static/` : فایل‌های استاتیک (CSS, JS, تصاویر)
- `media/` : فایل‌های آپلودی کاربر

---

## ⚙️ راه‌اندازی پروژه

### پیش‌نیازها

- Python 3.10+
- Django
- MariaDB
- pip

### مراحل نصب

 کلون کردن پروژه:
   ```bash
   git clone <repo-url>
   cd electra
   ```

 نصب وابستگی‌ها:
   ```bash
   pip install -r requirements.txt
   ```

 تنظیم تنظیمات دیتابیس در فایل `settings.py`

 اجرای مهاجرت‌ها:
   ```bash
   python manage.py migrate
   ```

 اجرای سرور:
   ```bash
   python manage.py runserver
   ```
