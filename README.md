<h1 style="text-align:center">Electra</h1> 
<p style="direction:ltr">التکرا ، یک پروژه مبتنی بر سیستم رای دهی و برگزاری پنل های انتخاباتیه  که براساس نیاز ها و خواسته های مختلف ارجاعی ساخته شده بیس سورس کد فورک زده شده و فیچرهای مختلف اون پیاده سازی شده و در حال اجراست 
</p>
